# Panea: An Imaginary Painting Club Showcase

Panea is a simple yet elegant showcase website envisioned for an imaginary painting club. It serves as a platform for the club to share their artistic creations with the world.

## Features

* **Art Showcase:** Provides a visually appealing platform to display the club's paintings.
* **Clean and Simple Design:** Offers an intuitive and easy-to-navigate user experience.
* **Responsive Layout:** Adapts seamlessly to various screen sizes and devices, ensuring a consistent viewing experience.

## How It Was Built

Panea's journey began with a foundational structure built entirely using **HTML** for content and **CSS** for styling. To enhance its visual appeal and ensure responsiveness across different devices, the website was subsequently adapted to leverage the **Bootstrap** framework. This integration provided a robust and well-structured styling and grid system.

## Why This Project Exists

This project originated as part of a series of assignments within the **_Full-Stack Web Engineer_ course by Codecademy**, which I undertook to deepen my understanding of web development principles and practices. By making this project public, my aim is purely **educational**, hoping it can serve as a learning resource or source of inspiration for others exploring web development.
