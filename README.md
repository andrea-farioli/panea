# Panea

## What

Panea is a simple showcase website for an imaginary painting club that aims to share their art with the world.

## How

Originally, this website was created from scratch using only HTML and CSS. Later, it was adapted with the Bootstrap framework for proper styling and responsiveness.

## Why

This project was part of a series in the _Full-Stack Web Engineer_ course by Codecademy, which I took to study web development. I am making it public purely for educational purposes.
